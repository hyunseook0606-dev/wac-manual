# WAC 창고 업무 전자 메뉴얼

웹: https://wac-warehouse-manual.vercel.app  
저장소: https://github.com/hyunseook0606-dev/wac-manual

## 인턴이 수정할 때 (이게 전부)

1. GitHub에서 **Download ZIP** (또는 clone)
2. **Cursor / Claude Code** 등으로 폴더 열기
3. AI한테 원하는 수정 말하기  
   예: `수칙에 박스 예시 추가해줘`, `이 사진으로 바꿔줘`
4. 결과는 편한 방식으로 공유  
   - 권한 있으면 GitHub에 올리기 (공식 웹 반영)  
   - 또는 **본인 Vercel**에 배포  
   - 또는 **드라이브 / 카톡**으로 파일만 전달

파일 경로·배포 설정을 외울 필요 없습니다.

## 로컬로 화면만 볼 때

```bash
npm install
npm run dev
```
